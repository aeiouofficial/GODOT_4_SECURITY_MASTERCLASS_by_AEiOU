How to Use This Book:
This book is structured as three independent but complementary Parts. Each Part can be read standalone, or you can follow
the complete sequence for a comprehensive security education. Every chapter is self-contained: you can jump directly to the
topic most relevant to your current project.
Each chapter contains: a threat summary, production-ready code (copy-paste ready for Godot 4.6), tables of attack vectors
and defences, and a cross-reference to related chapters. The Security Scorecard at the end of each Part provides a self-audit
checklist you can use before any release.
